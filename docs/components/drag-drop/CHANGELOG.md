# DragDrop Changelog

## Unreleased

- No unreleased changes.

## 0.27.0

- Added configurable gesture activation, edge scrolling and linear-gap targeting.
- Cancel interrupted drags and expose native disabled handle state consistently.

## 0.23.0

- Added the initial headless DragDrop foundation with pointer, touch-delay,
  keyboard, target, cancellation, direction, and announcement behavior.

- Expose active input type on draggable sources and handles for pointer-only presentation.
