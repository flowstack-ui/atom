## 0.27.0

- Fix keyboard collapse thresholds, trailing-panel focus recovery and pointer
  focus scrolling. Preserve focus when removing the focused panel.
- Add measured CSS units, cascading resizing, single-panel layouts, external
  store/provider and context hooks, panel commands, event layout/boundary data,
  and opt-in shared intersection dragging.

- Add headless adjacent-panel resizing, controlled sizes, constraints, collapse,
  pointer cancellation and accessible keyboard separators.
